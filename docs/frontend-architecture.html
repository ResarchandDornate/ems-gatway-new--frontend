Local JSON store

lib/server/central/store.ts. Appended by the collector; also holds acks, revenue master, push subscriptions.

NorthBound gateway

ems-api public endpoint returns 503. Kept for /k once a new path (likely an SSH tunnel) exists.

Background work on the server

Started once per Node process from instrumentation.ts. Each one stays off until its environment is configured.

Collector lib/server/central/collector.ts

Every 5 min: S2 key points, controller, solis, alarms, edge-ai, health. Every minute: one fast-bess sample per cabinet. Uses a read-only account (CENTRAL_COLLECTOR_EMAIL). Cannot backfill gaps the gateway never uploaded.

Push watcher lib/server/push/push.ts

Reads alarms with the collector's token and sends lock-screen Web Push alerts. Needs WEB_PUSH_* VAPID keys.

Backfill mobile_app_kunal_backend/gateway/backfill.ts

Fills the /k history chunk store from the gateway. Idle while the gateway path is down.

Rules the structure enforces

  • Readings, charts and exports use the backend's sample or event time, never the browser clock.
  • Bump the React Query buster in app/providers.tsx whenever a cached response shape changes, or returning browsers rehydrate the old shape.
  • Large series opt out of localStorage with meta: {persist: false} and keep their own store (lib/central/fastStore).
  • The gateway ID comes from /api/app-config at runtime, so changing it needs no rebuild.
  • Shell tokens and primitives live in app/globals.css; modules don't define their own.
